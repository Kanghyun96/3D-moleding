## 범위와 한계
사진 배경은 2D이며 장비, 궤도, 그림자, 입자는 3D입니다. 지형 전체를 다시 모델링한 자유 회전 3D 맵은 아닙니다.
배경과 어긋나는 자유 카메라 회전은 제공하지 않고 전체/추적 보기를 제공합니다.
장애물 영역은 사진에서 추정한 좌표입니다. 실제 측량 또는 CAD 기반 물리 검증이 아닙니다.
높낮이 반응은 노면별 시각적 모사이며 실제 장비 주행 데이터가 아닙니다.
차고지/사무실/장비 정보 연결과 추가 장비는 아직 구현하지 않았습니다.
원본 v1 구현은 archive/에 보관합니다.
