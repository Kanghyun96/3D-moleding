## 장비 카드와 P 주차장

장비 또는 상단 `장비` 버튼을 누르면 폭 294px의 카드가 열립니다. 모바일에서는 작은 하단 패널로 표시합니다. 시험 목적, 진행시간, 트랙 정보, 노면 정보를 각각 접고 펼쳐 입력합니다. 시간과 진행중/대기중은 직접 입력·선택하는 시험 정보이며 애니메이션이 값을 누적하거나 바꾸지 않습니다.

- 입력 후 자동 저장하며 `저장` 버튼으로 바로 저장할 수도 있습니다. 서버 성공 응답 후 저장 완료로 표시하고, 실패한 입력은 유지합니다.
- `주행`을 눌러 노면 목록을 열고 버튼 또는 지도에서 노면을 선택합니다. 평소 지도 클릭은 주행을 시작하지 않으며 장비 클릭을 우선합니다.
- 긴 주차선과 장비 앞뒤 축은 사용자가 표시한 오른쪽 외곽선에, 뒤 연결선과 주차면 배열은 왼쪽 외곽선에 평행합니다. 두 외곽선으로 사진 투영을 함께 보정했으며 `P로 복귀` 후에도 같은 방향으로 정렬합니다. 현재 장비는 위쪽 첫 주차면, 사진 좌표 `[610,61]`을 사용합니다. 저장 정보와 연결된 내부 자리 ID `P03`은 유지합니다. 아래쪽으로 이어지는 7개 주차면은 얇은 U자 선으로 표시하며 번호를 쓰지 않습니다. 실제 추가 장비의 크기·동시 출입은 해당 모델을 넣을 때 다시 검증합니다.
- 기본 화면에는 P만 표시합니다. `구역 이름`을 켜거나 주행할 노면을 선택하는 동안 이름을 볼 수 있습니다. X 진입로 표식과 점선 경로는 없습니다.
- 표시 이름은 A `윗 흙 노면`, C `중간 흙 노면`, B `아래 흙 노면`, D `습전 노면`, E `자갈노면`, F `콘크리트 왕복로`입니다. 기존 노면별 움직임은 유지합니다.

- `building-lighting.js`: 원본 사진을 창 유리와 차고지 내부에만 클리핑해 부드럽게 재조명. 창틀·기둥·반사·내부 바닥 질감을 보존하고 방/차고지별 밝기를 달리함. 문턱에는 낮은 밝기의 원근 방향 빛만 적용.

## 범위와 한계
사진 배경은 2D이며 장비, 궤도, 그림자, 입자는 3D입니다. 지형 전체를 다시 모델링한 자유 회전 3D 맵은 아닙니다.
배경과 어긋나는 자유 카메라 회전은 제공하지 않고 전체/추적 보기를 제공합니다.

## 이미지 출처와 편집
