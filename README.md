# TrackVision · Field Motion

필드 시험장 사진 위에서 Bobcat T-870(CTL) 및 Doosan DX-55(소형 굴착기) 장비가 주행하는 인터랙티브 Home 화면입니다.
사진 배경과 실시간 3D 장비·궤도·그림자를 결합합니다.

장비를 클릭하거나 상단 카드에서 장비를 선택하면 작은 접이식 시험 정보 카드가 열립니다. 시험 목적·진행시간(hrs)·시험 상태·좌우 트랙·노면별 시간을 직접 입력해 저장하고, 카드의 `주행`에서 노면을 선택합니다. 현재 Bobcat은 P03, DX-55는 P01 주차면에 위치합니다. 긴 주차선과 장비 앞뒤 축은 오른쪽 외곽선에, 뒤 연결선은 왼쪽 외곽선에 평행합니다. 번호 없는 얇은 주차선 7면을 표시하며 복귀 후 같은 위치·방향으로 정렬합니다.

구역 이름은 기본으로 숨기고 `구역 이름` 버튼으로 표시합니다. X 진입로 표식과 점선 주행선은 화면에서 제거했습니다.

현재 화면 확대, 직접 주행, 속도 조절, 노면 효과와 실제 시간 기반 야간 모드의 순서·검증 기준은 [Phase 1~3 작업 계획](PHASE_PLAN.md)에 정리했습니다.

## 실행

저장소 루트에서 정적 HTTP 서버를 실행합니다.

```sh
node server.mjs
```

브라우저에서 [http://127.0.0.1:8521/](http://127.0.0.1:8521/)을 엽니다.
ES 모듈을 사용하므로 HTML 파일을 직접 여는 방식 대신 HTTP 서버가 필요합니다.
Three.js와 이미지 자산은 저장소에 포함되어 있으며 CDN 연결은 필요하지 않습니다.

## 구현 내용

- 장비 선택 → 접이식 카드 → 주행 → A–F 노면 선택 → 순환/왕복 주행.
- P 주차·출차·복귀 방향 정렬과 장비별 시험 정보 서버 저장.
- F 콘크리트 왕복로: 서쪽 외곽 통로의 빨간 경로를 따라 왕복하고 양 끝에서 전진 방향으로 선회.
- E 북서쪽 외벽에 별도 출입구를 추가한 사진 배경.
- 주행 거리와 동기화한 좌우 궤도 회전 및 노면에 따른 차체·암 반응.
- 건물, 벽, 수목 경계와 가로등 기둥에 대한 차체·버킷 충돌 검사.
- 주차장 복귀, 주행 도중 일시 정지, 다른 노면 선택 시 안전한 직접 이동.
- 기본 1배 재생 및 1~10배 드래그 조절.
- 궤도 접촉 위치별 먼지·자갈·물/진흙 비산과 요철 차체 반응.
- 실제 한국 시각 기반 낮·밤 전환, 가로등 9곳, 사무실·차고지 불빛.
- 주요 시험장과 건물을 함께 보여주는 전체 보기 및 장비 추적 보기.

속도와 주행 거리는 시뮬레이션 값입니다. 배경은 사진이며 자유 회전 지형 모델은 아닙니다.
차고지·사무실의 업무 화면 연결과 실제 운행 정보 표시는 후속 작업입니다.

입력 정보는 `data/equipment.json`에 저장되며 이 파일은 Git에서 제외됩니다. 프런트엔드만 복사하는 정적 서버에는 저장 API가 없으므로 `node server.mjs`로 실행하세요. Home 이전 시 데이터 파일 이관 또는 같은 저장 API 연결이 필요합니다. [저장 구조와 Home 연결](field-simulation/integration/equipment-data.md)을 참고하세요.

## 검증 및 현재 상태

`node field-simulation/verification/run.mjs`로 검증합니다.
경로 25,127개 지점과 모션 442,385스텝, 노면 전환 30가지를 검사합니다.
F의 왕복·선회·복귀·중간 목적지 변경은 별도 `verification/concrete-results.json`에도 기록합니다.
출차·순환·복귀, 정지·재개, 재생 배속, 잘못된 사무실 관통 경로 차단,
데스크톱/모바일에서의 카메라 좌표와 전체 필드 맞춤을 검사했습니다.

실제 브라우저의 최종 화면·성능 검수는 아직 완료하지 못했습니다.
서버 재시작 후 정보 복원, 저장 충돌·실패 처리와 카드 조작 검증은 `verification/equipment-results.json`에 기록합니다.
노면 효과·한국 시각·정지 후 입자 소멸·가로등 주행선 간섭 검증은 `verification/phase3-results.json`에 기록합니다.
조명 메뉴에서 낮·해질녘·밤을 미리 볼 수 있습니다. 기본값은 실제 한국 시각입니다.
현장 좌표가 없어 새벽 06~07시, 해질녘 18~19시는 임시 기준이며 계절별 일출·일몰 계산은 아닙니다.
참고 영상, 중복 라이브러리 다운로드, 별도 앱의 전체 소스 백업은 저장소에서 제외합니다.
